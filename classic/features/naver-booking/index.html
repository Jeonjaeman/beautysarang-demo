네이버예약 연동 프로그램, 일반예약과 한 스케줄에서

네이버로 들어온 예약과 전화·방문 예약을 따로 보지 않아도 됩니다. 네이버예약이 들어오거나 바뀌면 프로그램 화면에 바로 알림이 뜹니다.

네이버예약 연동 기능 정의

뷰티사랑넷 네이버예약 연동은 네이버예약을 일반예약과 같은 스케줄에 표시하고 등록·변경·취소를 실시간으로 알려 주는 기능입니다.

연동 조건 — 네이버에 샵이 뷰티형으로 등록되어 있어야 연동할 수 있습니다.

이런 샵에 필요해요

  • 네이버예약과 전화 예약을 따로 확인하다 겹치기 예약이 생기는 샵
  • 네이버예약 알림을 놓쳐 확인이 늦어지는 샵
  • 휴무일이나 특정 시간에는 네이버예약을 받지 않아야 하는 샵
  • 네이버로 처음 온 고객에게도 안내 문자를 보내고 싶은 샵

네이버예약 연동 주요 기능

한 스케줄에 함께 표시
스케줄 메뉴에서 일반예약과 네이버예약을 함께 관리합니다. 네이버예약은 N 표시로 구분됩니다.
실시간 화면 알림
네이버예약 등록, 변경, 취소, 완료 때 화면 중앙에 알림창이 나타납니다.
네이버 알림 모아 보기
네이버 알림 목록에서 네이버예약만 따로 확인합니다.
서비스·직원 연결
프로그램의 서비스 항목과 직원을 네이버예약의 서비스·프로필과 연결합니다.
네이버예약막기
반복 또는 1회성으로 네이버예약을 받지 않을 날짜·시간을 정합니다.
예약 가능 기간·소요 시간
오늘부터 며칠 뒤까지 네이버예약을 받을지, 서비스별 할당 시간을 얼마로 할지 정합니다.
신규고객 문자
네이버예약으로 신규 고객이 등록되면 자동발송으로 설정한 문자를 보낼지 정합니다.
환불 규정 설정
방문 며칠 전 취소인지에 따라 환불 비율을 정해 둡니다.

연동하는 순서

  1. 네이버 등록 확인 — 네이버에 샵이 뷰티형으로 등록되어 있는지 확인합니다.
  2. 고객센터 연락 — 가입 후 고객센터(1833-3675)로 연락하면 연동 방법을 안내해 드립니다.
  3. 네이버 ID 연결 — 환경설정 > 네이버예약 연동설정에서 네이버 ID를 연결합니다.
  4. 서비스·직원 연결 — 네이버예약의 서비스와 직원 프로필을 프로그램의 서비스·직원과 연결합니다.
  5. 예약 받기 — 이후 네이버예약은 스케줄에 자동으로 표시되고 화면 알림으로 알려 줍니다.

자주 묻는 질문

뷰티사랑넷은 네이버예약과 연동되나요?

네. 네이버에 샵이 뷰티형으로 등록되어 있으면 연동할 수 있습니다. 연동하면 일반예약과 네이버예약이 하나의 스케줄 화면에 함께 표시됩니다.

연동 설정은 어떻게 하나요?

네이버에 샵이 뷰티형으로 등록되어 있다면 연동할 수 있습니다. 환경설정 > 네이버예약 연동설정에서 네이버 ID를 연결하며, 자세한 연동 방법은 가입 후 고객센터(1833-3675)로 연락하시면 안내해 드립니다.

네이버로 예약이 들어오면 어떻게 알 수 있나요?

네이버예약이 등록·변경·취소·완료되면 프로그램 화면 중앙에 알림창이 나타납니다. 네이버 알림 목록에서 네이버예약만 따로 모아 볼 수도 있습니다.

특정 날짜에는 네이버예약을 받지 않을 수 있나요?

네. 네이버예약막기 설정에서 반복 또는 1회성으로 네이버예약을 막을 수 있고, 네이버 예약 가능 기간도 정할 수 있습니다.
